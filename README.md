# SkillWeave – Smart Learning Platform (Frontend)

SkillWeave is a smart learning platform designed to provide personalized and interactive learning experiences. It helps students discover courses, access learning materials, attend assessments and track their learning progress.

The platform focuses on identifying students' learning difficulties and providing personalized recommendations to help them improve.

## Features

- Student, Instructor and Admin interfaces
- User authentication and role-based access
- Course browsing and enrollment
- Interactive lessons and learning materials
- Online quizzes and assessments
- Smart personalized learning recommendations
- Misconception Fingerprint – identifies possible misunderstandings using answers and confidence levels
- Learning recovery and progress tracking
- Responsive user interface

## Technology Stack

- React.js
- Vite
- JavaScript
- HTML5
- CSS3
- Bootstrap / Tailwind CSS (as implemented)
- Axios
- React Router

## Project Setup

### 1. Clone the repository

```bash
git clone YOUR_FRONTEND_REPOSITORY_URL
```

### 2. Navigate to the project folder

```bash
cd frontend
```

### 3. Install dependencies

```bash
npm install
```

### 4. Start the development server

```bash
npm run dev
```

The application will run at:

`http://localhost:5173`

## Environment Variables

Create a `.env` file in the frontend root directory when the API integration is ready.

```env
VITE_API_URL=http://localhost:5000/api
```

Use the deployed backend URL for production.

## Deployment

Backend API: Connected to the LearnSphere backend repository.
